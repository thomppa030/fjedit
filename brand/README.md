# fjedit's brand files

The marks fjedit shows of itself. Every file is an outline: nothing here needs a font to draw.

| File | What it is | Shown |
|------|-----------|-------|
| `fjedit-mark-dark.svg` | The logomark, a blue sun over its reflection, the lines indented as code is, in a square around its drawing | A group with no file open |
| `fjedit-tile.svg` | The logomark on a dark tile (#1e1f22, corners 22 of 100, the drawing 70 of 100) | The desktop and window icon |
| `fjedit-lockup-dark.svg`, `fjedit-lockup-light.svg` | Logomark and name side by side, for a dark and a light page | The README |

`-dark` marks are drawn for a dark ground: their lines and letters are light. `-light` marks are drawn for a light
ground. The name is always written in lower case, a sentence's start included.

The name sets Fira Sans Extra Condensed Light (SIL Open Font License) as outlines, the f and the j 80 units of the
em further apart than the font sets them; in a lockup the middle of the logomark's drawing sits on the middle of
the name, half the height of its f and d. The files are fjell's suite's, drawn with fjell's own (`assets/brand/` in
fjell's tree).
